# Contributing to FirstPR Buddy

Everyone is welcome, including first-time contributors! 🌱

1. Read the README to understand what the project does.
2. Pick a small change: fix unclear text, improve accessibility, add a quiz question, or correct a bug.
3. Fork the repository and create a new branch.
4. Test the site locally by opening `index.html` and checking the practice lab and quiz.
5. Open a pull request and explain what you changed and why.

Please be patient, constructive, and respectful when reviewing contributions. Never include real passwords or sensitive information in issues or pull requests.

## Ideas for first contributions

- Improve a beginner explanation.
- Add another plain-language analogy.
- Verify keyboard and screen-reader usability.
- Add translated instructions (with language labels).
- Make the practice simulation more realistic without running real commands.
