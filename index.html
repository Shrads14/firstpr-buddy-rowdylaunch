01 / LEARN

Open source, without the jargon.

You do not need to be an expert programmer to help. You can improve documentation, fix a typo, report a bug, or translate instructions.

📁

Repository (repo)

A project's shared folder. It holds the files, instructions, and change history.

Think: A shared class project folder.
📝

Issue

A task or problem someone has written down so contributors know what needs help.

Think: A to-do item.
🔀

Pull request (PR)

A request for the project owner to review your proposed changes before merging them.

Think: “Could you add my edits?”

The big picture

Six actions. One real contribution.

  1. 1FindChoose a project
  2. 2ForkMake your copy
  3. 3ChangeEdit something
  4. 4CommitSave the change
  5. 5PushUpload your work
  6. 6RequestAsk for review
